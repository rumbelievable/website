Coffee Table

About this project

After my first foray into woodworking, building a simple bookcase, I signed up for the intermediate class and decided to take on a real furniture piece. I found Spencley Design Co's Cody Coffee Table plans and couldn't resist.

I could wax poetic about it forever.

Lessons Learned

  • Wear a mask when sanding!!!
  • Getting a clean glue joint is so critical
  • Don't use oil-based polyurethane for finish

Favorite Part

I first built this in 2023 and this past winter I was getting twitchy with the fit and finish of the table, so I revisited it. Disassembled, new joinery, resanded, and refinished. Bam.
